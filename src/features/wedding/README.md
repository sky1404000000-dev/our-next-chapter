# Wedding Feature Structure

- `WeddingPage.tsx`: assembles the wedding invitation page in display order.
- `components/`: page-level controls and shared UI used across multiple sections.
- `sections/`: one folder per visible page section.
  - `hero/`: opening visual section.
  - `invitation/`: invitation text and wedding info.
  - `schedule/`: calendar and schedule.
  - `location/`: venue, map, and transport details.
  - `people/`: couple introduction.
  - `story/`: relationship story.
  - `gallery/`: photo gallery.
  - `guide/`: Pohang guide.
  - `account/`: account transfer section for the private route.
  - `closing/`: closing image and share actions.
